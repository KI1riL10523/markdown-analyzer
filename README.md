# Markdown Analyzer

Программа для анализа Markdown-документов на Scala 3 с использованием ZIO 2.
Читает `.md` файл, парсит его в AST, вычисляет статистику, рендерит в HTML и JSON.

---

## Возможности

- **Парсинг Markdown** в абстрактное синтаксическое дерево (AST):
    - Заголовки `# H1` ... `###### H6`
    - Абзацы
    - Списки: маркированные `- item` и нумерованные `1. item`
    - Цитаты `> quote`
    - Код-блоки с указанием языка
    - Таблицы `| a | b |`
    - Inline-элементы: `**bold**`, `*italic*`, `` `code` ``, `[link](url)`, `![image](url)`
- **Статистика документа** через моноид:
    - Количество заголовков, абзацев, списков, цитат, код-блоков, таблиц
    - Количество `bold`, `italic`, `code`, `links`, `images`
    - Общее количество слов
- **Рендеринг в HTML** с CSS-стилями
- **Сериализация в JSON** для машиночитаемого отчёта
- **CLI-интерфейс** с аргументами командной строки
- **Сборка в fat JAR** для запуска без sbt

## Архитектура

Конвейер обработки:

```
┌──────────────────┐
│   example.md     │  ← входной Markdown-файл
└────────┬─────────┘
         │  ZIO.readFile
         ▼
┌──────────────────┐
│   InlineParser   │  ← парсит inline: bold, italic, code, link, image
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│   BlockParser    │  ← парсит блоки: heading, paragraph, list, quote, code, table
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│   List[Block]    │  ← AST (модель данных)
└────────┬─────────┘
         │
    ┌────┼────────┐
    │    │        │
    ▼    ▼        ▼
┌─────┐┌──────┐┌──────────┐
│Analy││ HTML ││   JSON   │
│ zer ││Rend. ││ Renderer │
└─────┘└──────┘└──────────┘
    │    │        │
    ▼    ▼        ▼
 Stats  output.html   output.json
```

Ключевые принципы:
- Ядро — чистые функции: парсинг, анализ, рендеринг без побочных эффектов.
- Эффекты на краю: чтение/запись файлов вынесены в `FileService` через ZIO.
- ADT + pattern matching: все типы данных описаны как `enum`, обработка — через `match`.
- Моноид для агрегации: `Stats` — моноид, `combine` склеивает статистики.

## Установка

### Требования

- **JDK 21** или выше ([скачать](https://adoptium.net/))
- **sbt** ([скачать](https://www.scala-sbt.org/download.html))

### Сборка

```bash
# Клонировать репозиторий
git clone <url-репозитория>
cd markdown-analyzer

# Скомпилировать
sbt compile

# Собрать JAR
sbt assembly
```

После сборки JAR появится в:
```
target/out/jvm/scala-3.9.0/markdown-analyzer/markdown-analyzer.jar
```

### Использование

Через sbt:
```bash
sbt "run example.md output.html output.json"
```

Через JAR (без sbt):
```bash
java -jar markdown-analyzer.jar example.md output.html output.json
```

Аргументы:

| Аргумент | Описание |
|---|---|
| `<input.md>` | Путь к входному Markdown-файлу |
| `<output.html>` | Путь к выходному HTML-файлу |
| `<output.json>` | Путь к выходному JSON-файлу |

Пути могут быть относительными (относительно текущей директории) или абсолютными.

## Ограничения

Программа поддерживает подмножество Markdown. Осознанно не поддерживаются:

| Что | Почему |
|---|---|
| Экранирование (`\*`) | Требует предобработки строки |
| Многоуровневые списки | Требует отслеживания отступов |
| Сноски (`[^1]`) | Новый тип элемента |
| HTML-вставки (`<div>`) | Другой парсер |
| CommonMark полностью | Слишком объёмно для курсовой |
| Хвостовая рекурсия | Парсер переполнит стек на файлах >10 000 строк |

Возможные расширения:
- Экранирование — предобработка строки перед парсингом.
- Многоуровневые списки — учёт отступов.
- Стриминг — `ZStream` вместо `readFile`.
